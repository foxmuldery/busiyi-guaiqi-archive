# 《怪奇实录》异常档案库样板

这是上线前网站第一版样板，定位是“总入口 + 倒计时 + 8 个异常入口”。

## 文件结构

- `index.html`：页面结构
- `styles.css`：视觉样式
- `script.js`：倒计时、访问编号、弹窗交互
- `assets/archive-bg.png`：GPT 生成的暗档案库背景图

## 修改上线时间

打开 `script.js`，修改第一行：

```js
const launchAt = new Date("2026-06-01T20:00:00+08:00");
```

## 继续扩展入口

当前 8 个异常入口都已露出，其中 001 是 `PREVIEW` 状态，其余是 `SEALED` 状态。

后续可以按单集逐个扩展：

- 给入口加详情页
- 替换弹窗为分集档案
- 加预约/关注跳转
- 加分享结果卡
- 加每集专属图像资产

## 当前视觉方向

- 高级、神秘、诡异、简洁
- 克制的异常档案系统
- 黑灰主色，少量红色异常提示和冷绿色系统状态
- 不使用血腥、鬼脸、廉价恐怖元素
